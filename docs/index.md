# FlyingAreas

**FlyingAreas** est un plugin [QGIS](https://qgis.org) développé par le Groupe 51 de l'IMT Atlantique (projet PCE / FISEA2). Il permet de calculer, visualiser et gérer des **zones de vol de drones** directement dans QGIS.

## Fonctionnalités

- Sélection d'un drone parmi une base de modèles (dossier `Base_drones`)
- Calcul de zones de vol à partir des caractéristiques du drone et du contexte cartographique
- Mode d'**expansion** des zones
- Gestion des zones calculées (création, consultation, suppression)
- Intégration native dans l'interface de QGIS (boîte de dialogue et seconde fenêtre)
