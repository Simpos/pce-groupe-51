# Règle pour l'écriture du code Python 

Respecter au maximum les réglementation d'écriture Python ([PEP 8](https://peps.python.org/pep-0008/))

Pour les fonctions bien spécifier les types pour les arguments et le type de retour

```python
def foo(a:int,b:int)->None:
    pass
```

Pour les éléments privées d'une classe il n'y a pas besoin de respecter la réglementation PEP8


Pour la génération de documentation (entre nous) utiliser [pydoc](https://docs.python.org/3/library/pydoc.html)

`python -m pip install pydoc` pour l'installer

`python -m pydoc -w mon_script` pour lancer le module 

`python -m pydoc -b` pour lancer un serveur local
